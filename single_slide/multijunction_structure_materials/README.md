# 多结InGaAs设计与制备流程：材料分层详图版

单页16:9图片版PPT，延续红白学术风格及Times New Roman粗衬线英文字形。重绘立体结构，完整标注Cap、窗口、发射区、基区、背场、TJ、CGB及GaAs衬底材料。通过共享Subcell四层详图和TJ双层详图保证可读性。

六结中间Subcell2–5用省略号代替，九结中间Subcell2–8用省略号代替；首末子电池展开。多结保留CGB上方的基底TJ，单结保留原论文的AlGaAs/GaAs反型TJ和CGB兼BSF。

九级组分阶梯、六个制备模块和9结性能框沿用上一版。图片版内容为整页像素图，英文按Times New Roman字形生成，不含独立可编辑字体对象；中文讲稿和来源写入备注。
